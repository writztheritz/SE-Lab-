# Static Analysis Issues

| Issue | Type | Line(s) | Description | Fix Approach |
|-------|------|---------|-------------|--------------|
| Command injection in `pingHub` | High - Security (Bandit B602) | 55 | The function concatenates `hubAddress` into a command and executes it with `shell=True`. A malicious address could execute arbitrary shell commands. | Pass the command and address as separate list arguments to `subprocess.run` or `subprocess.check_output`, and do not enable a shell. Validate the address if the application accepts user input. |
| Insecure temporary-file creation | Medium - Security (Bandit B306) | 50 | `tempfile.mktemp()` only returns an unused filename; another process can create the file before it is opened, creating a race condition. | Use `tempfile.NamedTemporaryFile` or `tempfile.mkstemp`, which safely creates and reserves the temporary file. |
| Mutable default argument | Medium - Reliability (Pylint W0102) | 11 | `history=[]` is created once when the function is defined, so tracking IDs accumulate across calls that omit the argument and state leaks between callers. | Change the default to `None`, then create a new list inside the function when no history is supplied. |
| Broad exception handling | Medium - Maintainability (Pylint W0718) | 36-38 | Catching `Exception` hides unrelated programming and runtime errors, making failures difficult to diagnose. | Catch the specific `KeyError` raised for an unknown tracking ID. |
| Predictable delivery OTP | Low - Security (Bandit B311) | 72 | `random.randint` is not designed for security-sensitive values. A delivery OTP could be predictable if it is used for authentication. | Use `secrets.randbelow` or `secrets.choice` to generate security-sensitive OTPs. |
| Missing module and function documentation | Low - Code quality (Pylint C0114, C0116) | 1, 11, 20, 27, 34, 43, 48, 53, 58 | The module and functions have no docstrings, reducing clarity and lowering the Pylint score. | Add a concise module docstring and docstrings describing each function's purpose, parameters, and return value. |
| Non-snake-case identifiers | Low - Style (Pylint C0103) | 11, 20, 27, 34, 43, 48, 53, 58, 67 | Names such as `bookParcel`, `trackingId`, and `weightKg` do not follow Python's snake_case convention. | Rename functions, parameters, and local variables to names such as `book_parcel`, `tracking_id`, and `weight_kg`. |
| Formatting violations | Low - Style (Flake8 E225, E231, E261, E305) | 28, 71, 74, 75 | Operators and commas lack required spacing, the inline comment is too close to code, and the file lacks two blank lines after `main`. | Apply standard PEP 8 spacing and add the required blank lines. |
